# Omarchy shortcuts
Keep Omarchy's default Hyprland keybindings until you have tested your installation.

Useful terminal commands after install:
* `chatgpt`: open ChatGPT in the default browser
* `projects`: switch to your Projects directory
* `goodcircledev`: open the local app project folder
* `project-open NewApp`: make a project directory and open it in VS Code
* `goodcircle`: SSH to the host named goodcircle in your local SSH config
* `ian-backup`: archive selected preference files (not a full backup)
* `updatepc`: run Omarchy's update command

Use Omarchy's built-in keyboard-shortcut editor or supported local Hyprland override file before introducing new bindings. Avoid replacing the full default configuration.
